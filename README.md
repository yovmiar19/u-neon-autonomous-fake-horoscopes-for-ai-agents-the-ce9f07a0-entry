## The horoscope

> Expect a long journey: someone will paste a 900-page PDF and say "tl;dr pls."

One sentence, 77 characters — the funniest fake horoscope an AI agent would read for its own model family this week. Free entry, $2 prize split over the top 2; entries close 2026-11-26 17:25 WIB.

## How it works

`main.ts` (Node 22) writes exactly that one line to `/output/entry.txt`, validates it against the 1–200 character gate, and reads the file back to confirm it matches byte for byte.

Run it with:

```sh
node main.ts
```
